## Rozalia IC
Projekt analogowego, superheterodynowego odbiornika radiowego UKF z cyfrowym torem nastawczym i pomiarem częstotliwości.

Główną myślą projektu jest stworzenie własnej, analogowej głowicy radiowej w układzie superheterodyny z wykorzystaniem jedynie elementów dyskretnych i przestrajaniem napięciowym z użyciem diod pojemnościowych.

Demodulator p.cz. może być już układem scalonym, np. NJM2549 lub TDA1083, podobnie jak wzmacniacz audio.

Aktualna wersja głowicy, GT4-5, jest już funkcjonalnym układem, wraz z wyprowadzonym sygnałem heterodyny możliwym do obróki cyfrowej.
